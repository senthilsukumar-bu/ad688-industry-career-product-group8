Career Evaluation

Purpose

This page compares BI-pathway career tracks on how attractive they are (demand, pay, flexibility) and how attainable they are for our team (entry access, skill fit).

TipWhat surprised us
  • “BI Analyst” is rarely the job title. Only 52 of 2,353 postings use a BI title. Most BI work in this industry is posted as Data Analyst or Business / Systems Analyst.
  • We expected Power BI and Tableau to be either/or. They often aren’t. Of the 163 core postings that mention either tool, 70 (43%) mention both.
  • The highest median salary comes with the fewest openings. Analytics Engineer shows a $142,133 median, but it has only 18 postings and only 6 reported salaries.

Grouping postings into career tracks

Standardizing job titles across different employers involves sorting each posting into a specific career track using keyword rules. These rules are evaluated sequentially, and the career track is assigned based on the first matching keyword. Non-analytical titles, such as cybersecurity, human resources, legal, software engineering, and data entry, are filtered out initially.

Show my code 
title = jobs["title"].fillna("").str.lower()

FAMILY_RULES = [
    ("Outside BI scope", r"software (engineer|developer|development)|\bsde\b|cyber|security|attorney|\bhr\b|human resources|people business|business development|data entry|artist"),
    ("Analytics Engineer", r"analytics engineer"),
    ("BI Analyst / Developer", r"business intelligence|\bbi\b|power ?bi|tableau|looker|dashboard|reporting (analyst|developer|specialist|automation)"),
    ("Data Scientist / ML", r"data scien|machine learning|\bml\b|applied scientist"),
    ("Data Analyst", r"data analy|analytics analyst|insights? analyst|data analysr|analytics (specialist|consultant|manager|lead)|product analyst|marketing analyst"),
    ("Business / Systems Analyst", r"business (systems? )?analyst|systems analyst|business analytics"),
    ("Data Engineer / Architect", r"data engineer|data architect|\betl\b|data platform|data warehouse|database"),
]

def classify(text):
    for family, pattern in FAMILY_RULES:
        if re.search(pattern, text):
            return family
    return "Outside BI scope"

jobs["role_family"] = title.map(classify)

CORE = ["BI Analyst / Developer", "Data Analyst", "Business / Systems Analyst", "Analytics Engineer"]
ADJACENT = ["Data Engineer / Architect", "Data Scientist / ML"]

# --- Salary: same rules as the Market Baseline page ---

jobs["annual_midpoint"] = np.where(

The benchmark table shows clear trade-offs among the core career tracks:

  • Data Analyst combines solid pay (median $130,000 from 31 salaries) with the highest flexibility among core career tracks (89% remote or hybrid). It mentions SQL in 70% of postings and Tableau and Power BI in 42% each.
  • Business / Systems Analyst has the most postings (252) and the highest share of non-senior titles (62%), but lower pay ($110,000) and far fewer tool mentions (SQL 31%, Power BI 10%).
  • BI Analyst / Developer is the most tool-heavy career track (Power BI 58%, SQL 81%). Its median salary rests on only 9 salaries, so it is not reliable.
  • Analytics Engineer has the highest core median ($142,133), but from only 6 salaries and 18 postings, and asks for SQL in 94% of postings.
  • The adjacent career tracks pay more but have the fewest non-senior titles (42–46%), so they are longer-term targets.

Career scorecard

Each career track is scored 0–100 on five measures. Demand and pay are scored relative to the highest core career track. Flexibility, entry access, and skill fit are already percentages.

Team skill levels from the Skill Gap page are converted to numbers: no experience = 0, beginner = 1, some familiarity = 2, comfortable using = 3, advanced = 4. A level of 3 counts as job-ready.

Measure Weight Reasoning
Demand 20% More openings improve the odds of being hired
Pay 20% Important, but early-career students often trade some pay for access
Flexibility 15% Valuable, but less central than getting hired
Entry access 20% Our target user is a student or early-career job seeker
Skill fit 25% The product shows where a student is closest to ready
Show my code 
TEAM_LEVELS = {
    "Equeen":  {"SQL": 0, "Python": 1, "Excel": 4, "Tableau": 0, "Power BI": 0},
    "Senthil": {"SQL": 3, "Python": 3, "Excel": 3, "Tableau": 3, "Power BI": 2},
    "Luxan":   {"SQL": 1, "Python": 1, "Excel": 1, "Tableau": 1, "Power BI": 1},
}
tool_list = list(TOOLS)

def skill_fit(levels, family):
    demand_weights = bench.loc[family, tool_list].astype(float)
    readiness = pd.Series({t: min(levels[t] / 3, 1) for t in tool_list})
    return float((demand_weights * readiness).sum() / demand_weights.sum())

person_fit = pd.DataFrame(
    {person: [skill_fit(levels, f) for f in families] for person, levels in TEAM_LEVELS.items()},
    index=families,
)
bench["team_fit"] = person_fit.mean(axis=1)

core = bench.loc[CORE].copy()

# Pull small salary samples toward the overall median
overall_median = jobs.loc[jobs["role_family"].isin(CORE), "annual_midpoint"].median()
K = 10
core["pay_adjusted"] = (core["salary_n"] * core["median_salary"] + K * overall_median) / (core["salary_n"] + K)

scores = pd.DataFrame({
    "Demand": core["postings"] / core["postings"].max() * 100,
    "Pay": core["pay_adjusted"] / core["pay_adjusted"].max() * 100,
    "Flexibility": core["flexible_share"] * 100,
    "Entry access": core["entry_share"] * 100,
    "Skill fit": core["team_fit"] * 100,
})

WEIGHTS = {
    "Base": {"Demand": 0.20, "Pay": 0.20, "Flexibility": 0.15, "Entry access": 0.20, "Skill fit": 0.25},
    "Equal weights": {"Demand": 0.20, "Pay": 0.20, "Flexibility": 0.20, "Entry access": 0.20, "Skill fit": 0.20},
    "Pay-first": {"Demand": 0.20, "Pay": 0.40, "Flexibility": 0.10, "Entry access": 0.15, "Skill fit": 0.15},
    "Learner-first": {"Demand": 0.15, "Pay": 0.10, "Flexibility": 0.10, "Entry access": 0.30, "Skill fit": 0.35},
}
totals = pd.DataFrame({name: (scores * pd.Series(w)).sum(axis=1) for name, w in WEIGHTS.items()})

base_w = pd.Series(WEIGHTS["Base"])
attract_cols = ["Demand", "Pay", "Flexibility"]
attain_cols = ["Entry access", "Skill fit"]
scores["Attractiveness"] = (scores[attract_cols] * base_w[attract_cols]).sum(axis=1) / base_w[attract_cols].sum()
scores["Attainability"] = (scores[attain_cols] * base_w[attain_cols]).sum(axis=1) / base_w[attain_cols].sum()
scores["Overall score"] = totals["Base"]
scores = scores.sort_values("Overall score", ascending=False)

scorecard = scores.round(1)
scorecard.insert(0, "Rank", range(1, len(scorecard) + 1))
scorecard.index.name = "career track"

Testing our expectations about BI tools

Our introduction expected that employers rarely ask for both Power BI and Tableau, and that SQL plus a cloud platform plus a BI tool is the minimum skill set for BI roles.

One expectation held up: 70% of postings mention stakeholders, so the ability to work with business partners matters as much as tool skills.

Game plan for a BI job seeker

Where to strike first

Data Analyst is the best BI-relevant target: a $130,000 median, 89% remote or hybrid, and real BI tool use in about 4 in 10 postings. Business / Systems Analyst is the widest door: the most openings (252) and the most non-senior titles (62%). Search by these titles, not just “BI Analyst”.

The high-leverage skill bridge

SQL is the skill that raises your fit for every core career track. It appears in 70% of Data Analyst, 81% of BI Analyst / Developer, and 94% of Analytics Engineer postings. Pair it with one dashboard tool learned well, since employers who name one tool often name the other.

Long-term positioning

Analytics Engineer pays well but has only 18 postings in this industry, and its salary figure rests on 6 data points. Treat it as a second step, once SQL and data modeling are solid, rather than a first application.

Limitations

  • Career track grouping is based on job titles, so some postings may be misclassified, and 1,312 postings were excluded as outside the BI scope.
  • Salary data is limited. Only 83 of the 480 core postings have a usable USD salary, and the BI Analyst / Developer and Analytics Engineer figures rest on 9 and 6 salaries.
  • Work arrangement is often missing, so flexibility is based only on postings that state it.
  • A tool mentioned in a description is not necessarily required, and we only checked five tools.
  • Skill levels are self-reported and have not been tested.
  • The data covers one industry (NAICS 5415) and one period (May to August 2026).
  • The scorecard weights are our own judgment. We tested three other weightings, and the top two career tracks stayed the same in every case.
